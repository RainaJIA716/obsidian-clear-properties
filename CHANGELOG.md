# Changelog

## 0.1.1

- No changes to the plugin itself (`main.js` and `styles.css` are byte-identical to 0.1.0).
- Regenerated `package-lock.json` from scratch so the community review can install
  dependencies and verify the build.

## 0.1.0

First release.

- A line to the left of a note's properties, shown on hover (always shown on
  phones and tablets). Click its trash icon to delete every property of the note.
- A notice with **Undo**; ⌘Z / Ctrl+Z also works in editing view.
- Works in editing and reading view.
- Command: **Delete all properties of current note**.
- English and Chinese interface.
